Technology: Java, Java Swing, AWT
Project type: Desktop GUI application

HOW TO RUN
1. Install Java (JDK 8 or later).
2. Double-click QuizApplication.jar.
   If double-click does not work, open Command Prompt in this folder and run:
       java -jar QuizApplication.jar

SOURCE CODE
The src folder contains Main.java, WelcomeFrame.java, QuizFrame.java,
Quiz.java and Question.java.

OOP CONCEPTS USED
- Encapsulation: fields are private and accessed through methods.
- Abstraction: quiz operations are exposed through the Quiz class.
- Classes and objects: Question, Quiz and GUI frame classes.
- Constructors: initialize question objects and quiz state.
- Composition: Quiz contains a collection of Question objects.

FEATURES
- Player name entry
- Ten multiple-choice Java/OOP questions
- One answer selection per question
- Score and percentage calculation
- Result screen and restart option
